# Part 3 用户验收指南：申请材料工作台

Part 3 已进入 `user_acceptance`。本阶段完成事实绑定的定制简历、求职信和自我介绍草稿，以及 Reviewer、用户修订、不可变 Final 和经过验证的 PDF 导出。不会自动投递，也不会调用或开发 OpenCLI。

## 1. 升级数据库

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m career_console db migrate
.\.venv\Scripts\python.exe -m career_console doctor
```

迁移前会自动创建 SQLite 一致性备份。预期：

```text
DB revision  20260723_0004  20260723_0004  PASS
```

如迁移失败，不要删除数据库或备份。

## 2. 启动

```powershell
.\.venv\Scripts\python.exe -m career_console serve
```

打开 `http://127.0.0.1:8765`，侧栏应出现“申请材料”。

## 3. 验收前提

- 职业档案中有姓名、联系方式、学历、技能、工作或项目成果等 `confirmed` Facts。
- 岗位池中至少有一个真实岗位，并已完成匹配分析。
- `proposed` 和 `rejected` Fact 不会进入材料。

## 4. 实际验收流程

1. 在岗位详情点击“生成申请材料”，或进入“申请材料”选择岗位。
2. 先选择“定制简历”，填写基础系列名称并生成。
3. 核对生成内容：岗位匹配的事实应优先排列，每条正文右侧必须显示 Fact 值、类别、字段和版本。
4. 查看 Reviewer：硬条件缺口和岗位覆盖不足显示为风险；无引用表达、虚构数字、未解析占位符显示为阻断错误。
5. 在一条表达前增加受控引导语，例如 `重点经历：`，保存后应产生新内容版本并自动重新审查。
6. 尝试加入事实中不存在的数字或新职位描述，例如 `业绩提升 99%`，应产生 `unsupported_number` 或 `unsupported_claim`，并禁止 Final。
7. 修复该表达，确认 Reviewer 无阻断错误。
8. 点击“确认 Final 并导出 PDF”。成功后页面应显示页数、文件大小、文本层、渲染结果和 SHA-256，并显示第一页预览。
9. 下载 PDF，用本机阅读器检查中文字体、换行、层级、页脚和页数；复制一段文字确认 ATS 文本层可用。
10. Final 后再次尝试编辑，应被拒绝。
11. 回到职业档案修改一条已使用事实，再查看 Final 材料；历史 Fact 值、Fact version、正文、内容哈希和 PDF 均不得变化。
12. 再生成一份“求职信”或“自我介绍”，在“基础简历系列”中选择第 2 步创建的已有系列；生成后返回列表，系列名称应保持一致且材料计数增加。
13. 确认复用系列生成的所有表达同样绑定事实快照；选择“新建系列”时仍可创建相互独立的另一套基础材料。
14. 停止并重新启动服务，确认材料版本、Reviewer 结果、Final、系列归属和下载链接仍存在。

## 5. Reviewer 与编辑边界

本阶段默认使用离线确定性 Drafter–Reviewer，简历不会发送到外部模型。安全策略有意严格：

- 草稿只选择、排序和呈现 confirmed Facts。
- 编辑后的正文必须保留至少一条引用事实的完整原文。
- 可以调整标点和使用受控引导语，如“重点经历”“核心能力”“相关经验”“项目成果”。
- 不能通过编辑加入事实外的新数字或新陈述；需要补充经历时，应先在职业档案新增并确认 Fact，再重新生成材料。
- Reviewer 风险提示可以带到 Final，但阻断错误必须先修复。

这条限制优先保证不虚构。真实使用中如需更灵活的改写，请记录具体表达需求，后续可在同一事实引用门禁内扩展安全改写器。

## 6. PDF 验证内容

系统在 Final 前执行：

- ReportLab PDF 生成与中文字体嵌入；
- 1–3 页页数门禁；
- pypdfium2 文本层提取；
- pypdfium2 第一页真实位图渲染；
- 非空页面和合理画布尺寸检查；
- PDF SHA-256、文本层 SHA-256、字节数和 PNG 预览持久化。

只有文本层和实际渲染均通过时，版本才会进入 `final`。

## 7. 当前范围边界

- PDF 是本阶段正式导出格式；DOCX 暂不提供。
- 求职信为事实约束的首版切片，重点验证引用与版本闭环，不包含复杂信件模板市场。
- 不创建申请记录，不自动投递；这些属于 Part 4。
- 不批量生成大量材料，不使用 OpenCLI。
